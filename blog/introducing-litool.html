打造專屬的瑞士刀：LiTool 工具箱上線！解決農民曆計算與圖片壓縮痛點

2026年6月24日 · 閱讀時間約 4 分鐘
Liwen
Digital Architect / Full Stack Developer

在日常的開發與生活中，我們總會遇到需要一些小工具來輔助的時候。網路上雖然有很多免費的線上工具，但它們往往充斥著滿滿的廣告，或是剛好「缺了那麼一點點」我們需要的功能。

為了不再將就，我決定自己動手，打造一個乾淨、快速，且完全符合自己需求的專屬工具箱 —— LiTool (https://litool.liwen.studio)。

為什麼要自己做工具箱？​

這個專案的起點其實非常簡單：我需要算日子，但我找不到好用的農曆計算機。

我常常會使用日期計算的功能（像是推算某個專案的倒數天數、或是計算過去某天的間隔），但市面上的計算機通常只支援標準的西曆。當我需要把算出來的日期對應到「農民曆」或是「民國」年份時，我必須再開另一個網站手動轉換，用起來總覺得差點意思。

身為工程師，解決痛點的最好方法就是「自己寫一個」。於是，我以日期計算機為出發點，並將這個專案定位成一個可持續擴充的基礎平台，未來只要有任何覺得好用、實用的功能，我都能隨時加進這把「瑞士刀」裡。

現有的六大實用功能​

除了為解決個人痛點所開發的核心工具外，目前 LiTool 已經上線了 6 款非常實用的開發與生活輔助工具：

1. 萬能日期計算機​

這不只是一個普通的日期計算機，它特別針對了台灣使用者的習慣進行了深度優化：

  • 精準的間隔計算：可以計算總天數，也能自動幫您算出扣除週末的「工作日」。
  • 在地化的日期推算：當您推算未來或過去的某一天時，系統會「一鍵同步顯示」西曆、民國、與農曆！

2. 純前端圖片壓縮工具​

這是我後來加入的心頭好，完美解決了發文前圖片太大的困擾：

  • 隱私絕對安全：採用「純前端」瀏覽器運算技術，您的照片完全不會上傳到任何伺服器。
  • 支援批次與社群最佳化：內建 IG、FB、LINE 預設模式，並支援多圖一鍵打包 ZIP 下載。

3. JSON 格式化工具 (JSON Formatter)​

處理 API 回傳資料的最佳幫手，支援語法高亮、一鍵排版與壓縮，讓雜亂的資料瞬間變得井然有序。

4. 正規表達式測試器 (Regex Tester)​

開發者必備的神器，可以在網頁上即時測試您的 Regex 語法，並高亮顯示匹配結果，寫扣不再瞎猜。

5. Base64 編解碼工具​

快速處理字串的 Base64 編碼與解碼，介面乾淨簡單，無須擔心資料外洩。

6. Hash 雜湊產生器 (Hash Generator)​

支援 MD5、SHA-1、SHA-256 等多種常見的雜湊演算法，無論是驗證資料完整性或是加密測試都非常方便。

開發者視角：技術選型與亮點​

如果你也是開發者，或許會對 LiTool 背後的技術架構感興趣。這個專案不僅是個實用工具，也是我實踐前端新技術的實驗場：

  • 核心框架與 UI：使用 Next.js (App Router) 建構，搭配 Tailwind CSS 處理樣式。為了讓操作體驗更加滑順，我導入了 GSAP (@gsap/react) 來處理元件進場與切換的精緻動畫。
  • 日期魔法：在日期計算上，核心的加減邏輯依賴強大的 date-fns；而解決我最大痛點的「農曆轉換」，則是使用了 lunar-javascript 這個套件，完美計算出天干地支與農民曆日期。
  • 效能與隱私兼具的圖片壓縮：
    • 採用 browser-image-compression 套件，並開啟 useWebWorker: true。這意味著即使一次丟入數十張高解析度圖片，壓縮過程都在背景的 Web Worker 執行，完全不會卡死主執行緒 (Main Thread)，保持 UI 的流暢度。
    • 搭配 jszip 與 file-saver 實作了一鍵批次打包下載的功能。不僅達成了「零伺服器後端成本」，也帶給使用者最安心的隱私保障。

未來展望與結語​

LiTool 目前雖然只有幾項工具，但它的地基已經打好了。未來，我會繼續把日常工作、生活中遇到的各種「微小但頻繁的痛點」，化作一個個實用的小工具放上來。

如果你剛好也需要算個農曆日子，或是手邊有圖片需要快速無痛壓縮，歡迎來試用看看：
