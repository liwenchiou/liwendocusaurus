I'm Liwen.
A Digital Architect.

將複雜的商業需求轉化為堅固、優雅的現代網頁架構。我專注於系統設計、AI 協作工程，以及工程心理學的完美平衡。

開發哲學 (Philosophy)

我是一名「數位建築師」，深信技術只是手段，建立具備高度擴充性的系統才是目的。

從 React SPA 邁向 Next.js 全端架構，我的設計理念始終是：「高內聚、低耦合」。近期我更將專注力投入於 Agentic AI 的人機協作架構。透過打造專屬的「全域大腦 (Global Brain)」，我將工程心理學轉化為 AI 的防呆護欄 (Guardrails)，讓 AI 成為穩定輸出的隊友，確保團隊能在極速迭代中，依然安全、精準地交付商業價值。

開源架構: ezdcbot

為了解決 Serverless 環境下 Discord Bot 部署的痛點，我從零打造了這個 完全零依賴 (Zero Dependency) 的輕量級推播套件。

捨棄笨重的 WebSocket 建立連線，改採原生 fetch 實作，專注於高效能的 HTTP 請求與 Thread 管理，完美適配無伺服器架構。

開源架構: ghaction-lis

為了無縫追蹤 CI/CD 部署進度，我開發了這款 終端機專用的部署監聽器，能即時解析 GitHub Actions 狀態。

支援 PAT 認證與 CLI 自動串接，開發者能在終端機內直觀掌握部署成功或失敗原因，大幅降低在 IDE 與瀏覽器間頻繁切換的開發成本。
