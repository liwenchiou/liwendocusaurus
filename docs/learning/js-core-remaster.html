🏆 JS 核心重構：勇者轉職傳說

2026 iThome 鐵人賽 30 天挑戰系列文章，深入探索 JavaScript 核心概念與重構實踐。

📄️​Day 00 賽前宣言

本系列文為 iThome 鐵人賽「JS 核心重構：勇者轉職傳說」的前導宣言。深入探討 JavaScript 異步處理、作用域鏈、原型繼承與記憶體管理等底層機制，結合 RPG 勇者轉職體驗與視覺化圖解，幫助開發者打造穩健強大的前端與 Node.js 開發能力。

📄️​Day 01 控制台與第一眼

本章為 JavaScript 核心重構的第一天，我們將從最基礎卻最關鍵的「控制台 (Console)」開始。深入解析 console.log()、console.table() 與 console.dir() 等觀測語法的底層運作與適用情境，並解析為何應避免阻斷性的 alert()，建立正確的除錯思維。

📄️​Day 02 變數宣告與作用域

本章為 JavaScript 核心重構的第二天，我們將深入探討變數宣告與作用域的生存法則。在程式開發中，隨意宣告變數或無視作用域邊界是引發不可預期 Bug 的元兇。本篇將完整比較 const、let 與 var 的底層特性差異，包含區塊作用域 (Block Scope)、暫時死區 (TDZ) 的保護機制以及 typeof 型別辨析，帶領冒險者建立清晰的變數管理觀念與守衛法則。

📄️​Day 03 箭頭函式與隱形回傳

本章為 JavaScript 核心重構的第三天，我們將深入探討箭頭函式 (Arrow Function) 的極速語法與底層機制。對比傳統宣告式函式的繁複結構與提升 (Hoisting) 特性，解析箭頭函式如何利用語法簡化與隱形回傳 (Implicit Return) 達成一行俐落代碼；同時完整辨析傳統 function 與箭頭函式在 Lexical Scope 中 this 指向的本質差異，幫助冒險者擺脫沉冗咒語，掌握現代高階的極速開發技巧。

📄️​Day 04 寶箱與名單

本章為 JavaScript 核心重構的第四天，探討物件與陣列的容器差異與存取原理。了解如何運用物件的大括號與屬性標籤存放複合資訊，以及陣列的有序清單。學習傳值與傳址的基本觀念，擺脫選錯資料結構的窘境。

📄️​Day 05 記憶體傳址與副本

本章為 JavaScript 核心重構的第五天，將帶領你揭開記憶體底層的傳值 (Pass by Value) 與傳址 (Pass by Reference) 之謎。透過「影印術」與「倉庫提貨單」的比喻，解析物件分身術造成的意外連動災難，並初步介紹如何運用解構語法 (Destructuring) 建立安全的資料副本，穩固未來的不可變性 (Immutability) 基礎。

📄️​Day 06 展開運算子

本章為 JavaScript 核心重構的第六天，將帶領你破解陣列與物件的傳址詛咒。透過「爆破影印術」的比喻，解析如何運用展開運算子 (...) 瞬間斷開資料連結。本文更進一步探討淺拷貝 (Shallow Copy) 與深拷貝 (Deep Copy) 的差異及陷阱，穩固資料不可變性 (Immutability) 的實作基礎。

📄️​Day 07 記憶膠囊與閉包

本章為 JavaScript 核心重構的第七天，將帶領你揭開變數有效範圍與保護機制的秘密。透過「記憶膠囊與守護結界」的比喻，深入解析 IIFE (立即執行函式) 與閉包 (Closure) 的運作原理。教你如何建立獨立的時空來封裝資料，避免全域變數污染，穩固進階架構中的私有狀態管理基礎。

📄️​Day 08 物件導航與操作

本章為 JavaScript 核心重構的第八天，將帶領你學會如何優雅地處理龐大的物件結構。面對非有序的「混沌寶箱」，不再需要手動點名屬性。透過 Object.keys、Object.values 與 Object.entries 這三大現代化掃描儀，帶你把封閉的物件轉換為可隨意操作的陣列清單，大幅提升資料處理效率。

📄️​Day 09 陣列大戰與自動化生產線

本章為 JavaScript 核心重構的第九天，將帶領你告別手動、容易出錯的傳統 for 迴圈，引進全自動化生產線 map、filter 與 reduce 等現代陣列方法。透過這三大陣列職位，你將學會如何以「聲明式」語法來篩選、加工與歸納資料，並體會不可變性（Immutability）在專案維護中的巨大價值。
