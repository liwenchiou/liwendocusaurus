📄️資料持久化

👉 核心觀念：Docker 容器的特性是「用完即丟 (Stateless)」。當你刪除容器並重新啟動一個新的時，原本在容器內產生的資料（例如使用者上傳的圖片、資料庫的數據）都會瞬間蒸發！
