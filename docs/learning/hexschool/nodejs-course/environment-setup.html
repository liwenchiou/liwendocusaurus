環境建置與基礎操作

本章節將引導你完成 Node.js 開發環境的建置，以及學習開發時必備的終端機基礎指令。

命令提示字元 / 終端機操作​

不管你是使用 macOS 還是 Windows 系統，進行 Node.js 開發都離不開終端機。

常用基礎指令：

  • cd <資料夾名稱>：進入目標資料夾路徑。
  • cd ..：回到上一層目錄。
  • dir：(Windows 專用) 瀏覽當前所在位置的目錄內容。
  • ls：(macOS / Linux 專用) 瀏覽當前所在位置的目錄內容。

安裝 Node.js​

  1. 進入 Node.js 官方網頁：點此下載
  2. 建議選擇 LTS 版本 (Long Term Support)：LTS 版本代表官方會提供長期的穩定性與安全性維護，是最適合開發專案的版本。

Node.js 執行方式​

1. 使用 Node.js 開啟編譯核心 (REPL 環境)​

安裝完成後，可以在終端機確認安裝狀態並進入互動模式：

  • 檢查版本：輸入 node --version（或 node -v）。
  • 進入環境：直接輸入 node 即可進入互動環境，可以在裡面直接寫 JS 語法並執行。
  • 跳出環境：使用 Ctrl + C（按兩次）即可跳出 Node.js 環境。

2. 透過 Node.js 執行 .js 檔案​

這是在專案中最常用的執行方式：

  1. 使用終端機（如 cd 指令）進入 .js 檔案所在的資料夾路徑。
  2. 使用 node 檔案名稱.js（例如 node app.js）即可執行該程式碼。

使用 VS Code 執行與除錯 Node.js​

VS Code 提供了強大的 Node.js 偵錯工具：

  1. 透過 VS Code 開啟你的專案目錄。
  2. 進入側邊欄的 偵錯 (Debug) 模式（Run and Debug）。
  3. 可以在程式碼的行號旁點擊，設定中斷點 (Breakpoint)。
  4. 啟動偵錯後，程式會在跑到中斷點時暫停，讓你能夠針對該段程式碼查看變數狀態與執行結果。
