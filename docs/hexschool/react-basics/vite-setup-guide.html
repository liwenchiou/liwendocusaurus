使用 Vite 建立 React 專案

  1. 打開終端機（Terminal），輸入以下指令：
# 使用 npm 建立專案
npm create vite@latest

  1. 輸入專案名稱

  2. 選擇框架 (React)

  3. 選擇語言 (Javascript / Typescript)

  4. 接下來根據需求選擇，通常初始練習可選 No。

  5. 專案建立完成，下方有提示接下來要做的事：

  6. 進入專案目錄：

cd [您剛建立的專案名稱]
  1. 執行 npm install 安裝基礎套件：
npm install

  1. 執行 npm run dev 啟動開發伺服器：
npm run dev
