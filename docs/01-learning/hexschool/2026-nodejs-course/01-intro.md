# 2026 【後端】Node.js 直播班

歡迎來到 **2026 【後端】Node.js 直播班** 的學習筆記！

這份系列筆記記錄了我在這堂課中的所有學習歷程，從最基礎的 Node.js 環境建置、非同步處理，一路到打造完整的 RESTful API 與資料庫整合。

## 🎯 學習目標

1. **掌握 Node.js 核心概念**：理解 V8 引擎、Event Loop 以及非同步 (Asynchronous) 的運行機制。
2. **建置穩健的 API 伺服器**：從原生的 `http` 模組開始，進階到使用 `Express.js` 打造企業級的 RESTful API。
3. **資料庫整合與架構設計**：學習 NoSQL 資料庫 (MongoDB) 的操作，並實作 MVC 架構，讓程式碼更具可維護性。
4. **實戰專題演練**：每週的「主線任務」都是真實專案的縮影，幫助我們將理論轉化為實際的產出力。

## 💡 學習策略與提醒

- **動手實作大於一切**：所有的理論都需要透過敲打鍵盤來驗證。遇到 Bug 不要怕，那是進步的最佳養分！
- **善用主線任務防護線**：如果你正在跟著做每週的「主線任務實作」，強烈建議先自己嘗試思考邏輯。真的卡關了，再去點開筆記中的「程式碼解答」進行對照，這樣學習效果才會最深刻。
